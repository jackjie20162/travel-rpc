# travel-rpc

Global Dubai tourism platform RPC service.

## Repository

This repository is the dedicated tourism RPC service repository:
https://github.com/jackjie20162/travel-rpc

## Scope

- Product catalog
- Package/SKU
- Inventory and pricing
- Booking/order
- Traveler
- Voucher/redemption
- Tenant/merchant isolation

## Domain flow

Product -> Package/SKU -> Date -> Time Slot -> Inventory/Pricing -> Traveler -> Booking/Order -> Payment -> Voucher -> Redemption

## Development order

1. RPC + API
2. Payment / PayPal
3. Web/H5
4. App

## Documentation

All project documentation is maintained under `docs/`. Every development step must update the requirements, architecture, feature checklist and development log as applicable.
